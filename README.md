# LetsKite - Kiteboarding & Wing Foil School Template

A premium 10-page HTML/CSS/JS template for kiteboarding and wing foil schools.

## Features
- **Responsive Design**: Works perfectly across mobile, tablet, and desktop (360px to 1440px+).
- **Dark Mode**: Integrated dark/light mode toggle with system preference detection.
- **RTL Support**: Built-in RTL capability with toggle switch for Arabic/Hebrew layouts.
- **Modern Aesthetic**: Bold editorial layout, premium typography, and dynamic animations.
- **Form Validation**: Client-side validation on all forms (contact, booking, auth).

## Pages Included
1. `index.html` (Home)
2. `home2.html` (Alternative Home)
3. `lessons.html` (Courses and Rentals)
4. `instructors.html` (Team and Certifications)
5. `booking.html` (Booking Forms and Pricing)
6. `blog.html` (News Listing)
7. `blog-single.html` (Single Post)
8. `contact.html` (Contact and Location)
9. `login.html` (Authentication)
10. `register.html` (Account Creation)
11. `404.html` (Error Page)

## Technologies
- HTML5 (Semantic tags, JSON-LD Schema)
- CSS3 (Custom Properties/Variables, Flexbox, Grid)
- Vanilla JavaScript (ES6+, No jQuery)
- Phosphor Icons
- Google Fonts (Bebas Neue, DM Sans)

## Customization
- **Colors & Fonts**: Edit variables in `:root` inside `assets/css/style.css`.
- **Forms**: Replace Formspree placeholder URLs in `<form action="...">`.
- **Map**: Replace `YOUR_API_KEY` in the Google Maps iframe on the Contact page.
